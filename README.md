# 규연의 버킷리스트 · BUCKET LIST by 규연

카드를 눌러 뒤집어 보는 버킷리스트. 항목마다 **업적 칭호**가 붙고, 달성할수록 **전체 칭호(Lv.)**가 올라갑니다.
카드 뒷면에는 **내 사진과 메모**를 남길 수 있습니다.

- 공개 주소: <https://aeswdq.github.io/Bucket/> — 누구나 보기만 하는 화면(읽기 전용)
- 편집 모드: <https://aeswdq.github.io/Bucket/?edit=1> — 규연 님만 쓰는 화면
- 만든 사람: 규연 ([@AESWDQ](https://github.com/AESWDQ))
- 원본 디자인과 코드: [BUCKET LIST by JinH](https://github.com/Admin0/bucket) — "맘대로 갖다 쓰셈"이라고 해서 갖다 썼습니다.

## 공개 화면과 편집 모드

| | 공개 화면 (기본) | 편집 모드 (`?edit=1`) |
| --- | --- | --- |
| 보이는 기록 | 저장소에 커밋된 `data/published.json` | 이 브라우저의 기록 (`localStorage` · `IndexedDB`) |
| 카드 뒤집기 · 사진 크게 보기 · 필터 | 됩니다 | 됩니다 |
| 달성 표시 · 포기 · 삭제 · 항목 추가 | 없음 (감춤) | 됩니다 |
| 사진 넣기 · 바꾸기 · 지우기 | 없음 (감춤) | 됩니다 |
| 메모 | 있는 메모를 읽기만 | 쓰고 고칠 수 있음 |
| 관리(tune) 버튼 | 없음 | 있음 |

- 공개 화면은 **저장소에 아무것도 쓰지 않습니다.** 방문자가 무엇을 눌러도 규연 님의 기록은 그대로입니다.
- 편집 모드는 바꾼 내용을 **그 브라우저에만** 저장합니다. 공개 페이지에 올리려면 아래 「공개하기」를 하면 됩니다.
- 어느 화면인지는 바닥글의 **편집 모드** / **공개 화면으로 보기** 링크로 오갑니다. 편집 모드에서는 화면 아래에
  `편집 모드 — 변경 후 JSON과 사진을 성원에게 보내면 공개 페이지에 반영됩니다` 띠가 늘 떠 있습니다.

## 공개 기록 (`data/published.json`)

공개 화면이 보는 파일 하나입니다.

```json
{
  "format": "bucket-published-v1",
  "updated": "2026.11.22",
  "owner": { "name": "규연", "handle": "AESWDQ" },
  "items": {
    "mt01": { "done": "2026.11.21", "memo": "카드 뒷면에 나올 글", "photo": "img/memories/mt01.jpg" },
    "tr03": { "done": "2026.10.02", "memo": "제주 한 달. 숙소는 애월, 렌터카는 첫날부터.", "photo": "img/memories/tr03.jpg" },
    "tr11": { "memo": "아직 안 했지만 적어 두고 싶은 말" }
  },
  "fail": ["tr09"],
  "hidden": ["lf12"],
  "added": [
    { "id": "add_k3f9", "cat": "travel", "t": "제목", "d": "설명 한 줄", "a": "업적 칭호", "b": "" }
  ]
}
```

- `items` 의 key 는 `data/bucket.js` 의 항목 `id` 입니다. `done`(달성 날짜) · `memo` · `photo` 중 있는 것만 카드에 나옵니다.
- `photo` 는 저장소 안의 경로입니다. 사진은 `img/memories/` 에 두고 `img/memories/<id>.jpg` 로 적으면 됩니다.
- `fail` 은 포기한 항목, `hidden` 은 공개 화면에서 감출 항목, `added` 는 `bucket.js` 에 없는 직접 추가한 항목입니다.
- 이 파일을 못 읽으면(없거나 깨지면) `data/bucket.js` 에 날짜가 적힌 항목만 달성으로 보여 주고 나머지는 조용히 넘어갑니다.

## 공개하기 — 편집 모드에서 바꾼 것을 올리는 법

1. `?edit=1` 로 들어가 카드를 뒤집고 달성 · 포기 · 삭제 · 메모 · 사진을 정리합니다.
2. 오른쪽 위 **관리(tune)** → **공개용 내보내기 (JSON + 사진)** 을 누릅니다.
3. `bucket-publish-YYYYMMDD.zip` 이 내려받아집니다. 안에는 `published.json`, `img/memories/*.jpg`, `README.txt` 가 있습니다.
4. 그 zip 을 성원에게 보내면 저장소의 `data/published.json` 과 `img/memories/` 를 바꿔 커밋하고, 몇 분 뒤 공개 페이지에 반영됩니다.

zip 은 압축 없이(store) 담습니다. 사진은 이미 긴 변 900px · JPEG 로 줄여 두었기 때문입니다.
내보낼 때 사진은 **이 브라우저에 있는 사진 → 이미 공개된 사진** 순서로 담고, 편집 모드에서 지운 사진은 빠집니다.

## 쓰는 법 (편집 모드)

| 하고 싶은 것 | 하는 법 |
| --- | --- |
| 카드 뒷면 보기 | 카드를 **누르면** 뒤집힙니다. 다시 누르면(또는 뒷면 오른쪽 위 ×) 앞면으로 돌아옵니다. |
| 사진 넣기 · 바꾸기 · 지우기 | 뒷면의 **사진 넣기**(또는 사진 위 **바꾸기**) → 사진 선택. 지우기는 사진 오른쪽 위 휴지통. |
| 사진 크게 보기 | 뒷면 사진을 누릅니다. 아무 곳이나 누르면 닫힙니다. |
| 메모 쓰기 | 뒷면 **메모** 칸에 그냥 타이핑하면 자동 저장됩니다(‘저장됨’ 표시). |
| 달성 표시 | 카드 왼쪽 네모칸, 또는 카드 위의 업적 칭호를 누릅니다. |
| 포기 / 삭제 | 카드를 뒤집고 **포기** · **삭제** 버튼. 삭제는 되돌릴 수 있습니다. |
| 지운 항목 되살리기 | 오른쪽 위 **관리(tune 아이콘)** → 삭제한 항목 → 되살리기 |
| 항목 추가 | 관리 → 항목 추가 (카테고리 · 제목 · 설명 · 업적 칭호) |
| 공개 페이지에 올리기 | 관리 → **공개용 내보내기 (JSON + 사진)** → 받은 zip 을 성원에게 |
| 기록 내보내기 | 관리 → 진행 상황 내보내기 (JSON, 메모 포함) |
| 처음부터 다시 | 관리 → 진행 초기화 |

**업적 칭호**는 항목마다 하나씩 있습니다. 아직이면 회색 점선 실루엣, 달성하면 카드 위에 색이 채워진 인장으로 바뀝니다.
**전체 칭호**는 달성 개수로 오릅니다: Lv.1 모험 입문자(0) → Lv.2 퀘스트 수습생(5) → Lv.3 필드 탐험가(15) → Lv.4 베테랑 챌린저(30) → Lv.5 그랜드 마스터(50) → Lv.6 인생 레전드(80).
카테고리마다 따로 붙는 칭호도 있습니다(예: 여행 8개를 깨면 "지구의 방랑자"). 카테고리 제목 옆에 붙습니다.

편집 모드의 달성·포기·삭제·추가 기록과 메모는 이 브라우저의 `localStorage`(`bucket.state.v1`)에, 사진은 **IndexedDB**(`bucket.photos.v1`)에 저장됩니다.
사진은 넣을 때 긴 변 900px · JPEG 품질 0.82로 줄여 저장하므로 카드마다 한 장씩 수십 장을 넣어도 `localStorage` 5MB 한도에 걸리지 않습니다.
편집 모드의 기록은 **그 브라우저 하나** 기준입니다. 다른 기기에서는 공개된 기록에서 이어서 시작합니다.

data/published.json        공개 기록: 달성 날짜 · 메모 · 사진 경로 · 포기 · 감춘 항목 · 추가 항목

js/main__published.js      data/published.json 읽기

js/main__initialize.js     공개 기록을 먼저 읽고, 모듈과 스크립트를 순서대로 불러와 시작
js/main.js, main__info.js, main__setting.js, main__columns.js
                           원본 JinH 코드 (필터, 통계 대시보드, 설정, 카드 배치)

module/setting.html        설정 패널
css/style_rank.css         업적 칭호 · 전체 칭호 · 관리 패널 스타일

### 카드 뒷면 구성

```
.back > .bin
  .b_head      제목 + × (앞면으로)
  .ach_back    업적 한 줄
  .b_done      달성 날짜 (달성한 카드에만)
  .b_desc      항목 설명(있다면)
  .shot        사진 — 편집: 사진 넣기/바꾸기/지우기 · 공개: 사진만
  .file_in     <input type="file" accept="image/*"> (숨김, 편집 모드만)
  .memo_wrap   편집 모드의 메모 입력칸
  .memo_ro     공개 화면의 메모 (읽기 전용)
  .acts        달성 · 포기 · 삭제 (편집 모드만)
```

카드를 누르면 `.card.flipped` 가 붙고, 그동안만 카드 높이를 뒷면 높이에 맞춰 키운 뒤 `masonry('layout')` 으로 아래 카드를 밀어냅니다.
버튼·입력칸·사진·메모처럼 누르는 것들은 `js/main__app.js` 의 `NO_FLIP` 목록으로 거른 뒤집히지 않게 했습니다.
`b` 는 항목의 긴 설명으로, 카드를 뒤집으면 제목 아래에 나옵니다.

## 항목 추가하기

`data/bucket.js` 를 열고 원하는 카테고리의 `items` 에 한 덩어리만 더하면 됩니다.

```js
{ id: "tr21", t: "카드 제목", d: "설명 한 줄", a: "업적 칭호", b: "카드를 뒤집으면 나오는 이야기" }
```

- `id` 는 달성 기록의 열쇠입니다. 한 번 정하면 바꾸지 마세요.
- 화면에서 바로 추가하려면 **관리 → 항목 추가** 를 쓰면 됩니다. 이 경우 공개 페이지에도 나가려면 공개용 내보내기를 해야 합니다
  (`published.json` 의 `added` 로 들어갑니다).

## 미리보기

`index.html` 은 `module/*.html` 을 서버에서 받아 끼워 넣습니다. 파일을 그냥 열면 카드가 보이지 않으니,

```
python3 build_preview.py
```

로 `preview.html` 을 만들어 열면 됩니다. 원본 파일은 건드리지 않고, `data/published.json` 내용도 파일 안에 넣어 둡니다.
