# img/memories — 공개하는 사진

공개 페이지에 올릴 사진을 두는 폴더입니다. `data/published.json` 의 `photo` 값에 이 폴더 안의 경로를 적으면
카드 뒷면에 사진이 나옵니다.

```
"mt01": { "done": "2026.11.21", "memo": "…", "photo": "img/memories/mt01.jpg" }
```

- 파일 이름은 항목 id 를 그대로 쓰는 것이 가장 간단합니다 (`tr01.jpg`, `mt01.jpg` …). 다른 이름도 됩니다.
- 사진은 긴 변 900px · JPEG 품질 0.82 정도로 줄여 두면 페이지가 가볍습니다.
- 편집 모드의 **관리 → 공개용 내보내기**로 받은 zip 안에 `img/memories/` 폴더가 들어 있습니다. 그 파일들을
  이 폴더에 그대로 풀어 넣으면 됩니다.
